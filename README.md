# stash

Presets for Pure Data vanilla: store, recall, glide, morph and randomise.
Pure abstractions, no externals needed. Works in Pd 0.54+ and plugdata.

## Install

In Pd: Help > Find externals, search `stash`, install.

## Objects

| Object | What it does |
| --- | --- |
| `stash/param` | One parameter: float (lin, exp, step), list or symbol. Wire it or bind it to a GUI by send/receive names |
| `stash/bank` | Store, recall, glide, morph, mix, copy, delete, rename, exclude, random, dump, slots, write, read, scan |
| `stash/array` | A whole array as one parameter, morphs point by point |
| `stash/morph` | x/y pad blending four slots, or a crossfader for two |
| `stash/ui` | Preset panel: slot, store, recall, previous, next, slot label |

Everything with the same namespace talks without wires. Open each help file for examples.

## Quick start

```
[hsl] -> [stash/param synth cutoff 20 20000 exp] -> your filter
[stash/bank synth]
[store 1(  [recall 1 500(  [morph 1 2 0.5(  [write(
```

Or skip wrapping: name your sliders' send names `synth-...`, save the patch, then `[scan mypatch.pd(`.

## File format

Plain text next to your patch (`<namespace>.stash.txt` by default), one line per value:

```
1 cutoff 300;
1 steps 1 0 0 1;
2 _name bright pad;
```

## Development

The abstractions are generated by the scripts in `tools/` (`build_param.py`, `build_bank.py`, `build_small.py`, `build_help.py`). Edit the script, run it, and the .pd file is rewritten.
